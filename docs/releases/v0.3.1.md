> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## What's fixed

- **Recording outside Night-loop.** Keys and clicks in other apps, the desktop or a game are recorded again.
  The recorder used to do slow checks inside Windows' input hooks, and Windows quietly switches off hooks that
  answer too slowly, so recordings came back empty.
- **Night-loop hides while recording.** It minimizes when you press Record and comes back with the new blocks
  in view when you stop with the record key.
- **Clearer message when nothing was kept,** saying whether the keys went to Night-loop itself or never
  reached it (for example an app running as administrator).

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
