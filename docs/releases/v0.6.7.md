> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## Fixed

- **Pick on the live screen saved the outline into pictures.** With live picking on, the purple outline and tint
  you drag were captured along with the picture (and the overlay could tint a picked color). The picture block
  then found the shape but said the colors didn't match. Now the pixels are taken right after the overlay closes,
  so pictures and colors are exactly what's on screen. **Capture pictures picked in live mode with 0.6.5 or 0.6.6
  again** to fix them.

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
