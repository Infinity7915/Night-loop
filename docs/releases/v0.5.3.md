> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## New

- **Close window block** (Window section). Closes a program, the macro's game by default or any program you pick.
  - **Close (like clicking X)**: the program closes normally and can still ask to save. If it hasn't closed after
    the wait time, the macro goes on and leaves it open.
  - **Close, then force if it's still open**: the same, but ends it if it's still open after the wait time.
  - **Force close now**: ends it straight away, like End task in Task Manager. Unsaved work is lost.

  It never closes Night-loop itself or the parts of Windows that keep the desktop running (like Explorer).

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
