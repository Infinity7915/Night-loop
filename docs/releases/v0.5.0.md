> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## What's new

- **More exact record and replay.** Mouse movement is sampled twice as often, recorded paths now keep how fast
  the mouse moved along them (not only where it went), movements and short pauses replay on a steady clock so
  long macros don't drift, and the cursor lands on the exact recorded pixel. Recording still works while
  Night-loop is hidden in the system tray, and it stays in the tray afterwards.
- **Start keys save on their own.** Picking a macro's start / stop key saves it to your account straight away;
  there's no need to press Save. Several macros can now share one key, which starts them together (turn on
  **Run alongside** on them so one doesn't pause the other).
- **Download my data.** Settings › Account › **Download my data** (next to Delete account) saves a text file in
  a folder you choose with your email, username, how long you've used Night-loop and how many macros you have.
  Your password shows as "set (hidden)": Night-loop only keeps a one-way hash of it, so it can't be shown. The
  macros themselves aren't included.

## Terms of Service

The [Terms of Service](https://github.com/Infinity7915/Night-loop/blob/main/terms-of-service.md) were updated
(version 2026-11-05). **Section 5:** macros created and stored with Night-loop are assets of Night-loop and are
not owned by the user. Macros can only be made with the macro editor and can't be imported or exported. The
app shows this on the create-account screen and under your saved macros.

## Security

- The server refuses requests with fields it doesn't know (for example macro files from other programs), caps
  how many new macros an account can make per day, caps wrong-password attempts on account changes, and sends
  stricter security headers.

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
