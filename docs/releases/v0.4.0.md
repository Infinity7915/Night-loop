> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## What's new

- **Keeps running in the tray.** Closing the window now hides Night-loop to the notification area (by the clock)
  so your hotkeys and macros keep working. Click the icon to bring it back; right-click › **Exit** quits. Turn it
  off in Settings › Appearance › **Keep running in the tray when closed**.
- **Real Windows notifications.** The Notify block (its "Toast" type is now called **Notify**) sends a Windows
  notification instead of a message inside Night-loop.
- **Image gone and Pixel gone.** Two new Detect blocks wait until a picture leaves the screen, or until a point
  stops being a color, like a loading screen closing.
- **Fits any screen.** The first window size now comes from your screen, and the whole UI shrinks evenly when the
  window gets smaller, so a small laptop screen shows everything a big monitor does. The block editor always
  stays beside the timeline.
- **Block editor follows scrolling.** With more blocks than fit on screen, the block editor slides down beside
  the timeline as you scroll, so it's always in sight. Settings › Macros › **Block editor follows scrolling**.
- **One Select all button.** It ticks every block, and a second click unticks them. The separate clear button is
  gone (Esc still clears).
- **Record mouse movement** is on by default.
- **Touch screens.** Swipe to scroll every page; taps work on buttons and blocks.
- **Terms of Service.** The create-account screen links to the new
  [Terms of Service](https://github.com/Infinity7915/Night-loop/blob/main/terms-of-service.md), which lists
  everything Night-loop records and stores.

## Privacy and security

- Your macros (names and every block) and group names are now **encrypted** on the server, like your email
  already was. Passwords were never stored, only a one-way hash.
- The server now keeps your account's creation date and how long Night-loop has been open (for usage stats).

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
