> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## New

- **"Infinite" everywhere.** Every setting that can go on with no limit now uses the same word, Infinite: Loop
  times, Repeat until's Max tries, the Timeout on wait blocks (Wait for text, image, pixel, Image gone, Pixel gone,
  Wait for window, Open window) and the macro's Repeat option. Type **Infinite** in the box. The old ways (0,
  Forever) still work, and your macros keep working as they are.
- **Scroll block** (Input): pick Up or Down and how many **ticks** of the scroll wheel to turn, 1 to 50.

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
