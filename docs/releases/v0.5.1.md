> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## Fixed

- **Recording while Night-loop is minimized or in the tray.** Record's background helper that sorts each key
  and click could quit the moment recording started, so nothing was sorted until you stopped recording. By then
  Night-loop was back in front, and every key and click looked like it was aimed at Night-loop and got skipped
  ("all keys and clicks went to Night-loop itself"). The helper now always runs, recording is finished before
  Night-loop comes back, minimizing hands focus to the app behind, and a minimized or hidden Night-loop never
  counts as "itself".

## New

- **Remember window size and position.** Night-loop opens where it was, at the size it was, when you last
  closed it. Settings › Appearance › **Remember window size and position** (on by default). Turn it off to open
  centered at the default size. If the saved spot is on a monitor that's no longer plugged in, it opens centered.
- **Reset to default size and position** button under that switch puts the window back in the middle of the
  screen at the default size straight away, whether the switch is on or off.

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
