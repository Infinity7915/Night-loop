> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## What's new

- **Six new themes.** Settings → Appearance → Theme now has Rose, Blood moon, Ocean, Cyber, Lunar and Vanilla
  (a warm cream light theme) next to the original Night. Each one comes with an accent that suits it, and you can
  still pick any accent after.
- **Select several blocks at once.** The tick on each timeline row now selects it. Tick one block, then
  Shift+click another to select every block in between. Ctrl+A selects them all and Esc clears the selection.
- **Move or delete the selection together.** The bar next to Humanize has Move up, Move down and Delete for the
  selected blocks. A selected If, Loop or Repeat until moves with everything inside it.
- **Turning a block off** is now the "Block on" switch at the top of the block editor.

## What's fixed

- **Recording into an If.** After you play a macro, the row it stopped on no longer stays lit up like a
  selection, which made Record add new blocks at the end instead of under the block you meant. When recording
  starts and stops, the status line now says exactly where the new blocks go, for example "after block 05 inside
  the If".

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
