## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user (no admin needed) and adds Start menu
  and desktop shortcuts. Installed copies update themselves.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Needs Windows 10 (1809) or later, 64-bit. .NET is included, nothing else to install.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.

## You also need the server

Night-loop signs you in and stores your macros on the Night-loop server. There's no public server yet, so run
[Night-loop-Server](https://github.com/Infinity7915/Night-loop-Server) on your PC (its README has the steps) or
point the app at yours with `serverUrl` in `%LOCALAPPDATA%\NightLoop\settings.json`. Without one, the app opens
on a "can't reach the server" screen with a Retry button.

## What's in it

- Record keyboard and mouse, replay with real Windows input, loops, humanize, target-game lock.
- Ctrl+Alt+End stops every macro and releases all keys.
- Accounts with emailed codes; macros sync to your account (up to 15).
- Home screen: greeting, stopwatch, active macros, update status and announcements.
- Automatic updates from GitHub Releases: checked on launch, on Refresh, from Settings → Check now and every
  4 hours. Only the changed parts are downloaded.
- Smooth page transitions.
