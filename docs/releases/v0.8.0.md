> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## Lighter

- **About 30% smaller.** Installed, Night-loop takes about 129 MB instead of 186 MB, and the download is about
  20% smaller. It no longer ships 13 translated copies of Windows' built-in error messages, the unused WinForms
  library, or the parts of the Windows SDK it doesn't use.
- **Less memory and a quicker start.** Windows' text recognition now only starts the first time a macro reads text,
  the tray icon talks to Windows directly instead of loading WinForms, and Night-loop's own code comes
  pre-compiled.

## New

- **Settings › Macros › Wait after clicks** (slider, starts at 0 ms): a pause after Click, Drag, Find & click and
  Scan & turn blocks.
- **Settings › Macros › Wait after every block** (slider, starts at 0 ms): a pause after every block. Clicking blocks
  only get it when their wait after click isn't 0, so quick clicks and drags stay quick.
- **Wait after click on the block itself**: Click, Drag, Find & click and Scan & turn have a slider in the block
  editor. Until you move it, it follows the Settings slider (and changes with it). Moved, it keeps its own value;
  **Follow Settings again** undoes that. Changes apply straight away, even to macros already running.

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
