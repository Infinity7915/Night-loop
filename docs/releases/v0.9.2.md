> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## New

- **Collapse If, Loop and Repeat until blocks.** Their rows have an arrow on the right. Click it to hide the
  blocks inside (and the End) so long macros are easier to read; the row then says how many blocks are inside.
  Click it again to show them. Everything starts expanded, and collapsing only changes the view: the hidden
  blocks still play.
- While a macro plays, a collapsed block lights up when a block inside it is running, and Follow the playing
  block keeps that row in view. It stays collapsed.
- Moving a block up or down past a collapsed block jumps over the whole of it, and moving the collapsed block
  takes everything inside with it. Adding, pasting or recording under a collapsed block puts the new blocks
  after its End.
- When a run stops with an error inside a collapsed block, it opens so you can see the block.

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
