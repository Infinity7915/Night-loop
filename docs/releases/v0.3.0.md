> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## What's new

- **Record under the selected block.** Select a block and press Record: the new actions go right after it.
  With the last block (or nothing) selected they go at the end, and an empty macro records as before.
- **Play from the selected block.** Play now starts at the highlighted block ("Play from 7"). Step is gone
  for now.
- **Your own record key.** The key next to Record (F9 unless you change it) starts and stops recording. It's
  also in the loaded macro's options.
- **Overlapping keys.** Recordings keep how long each key and button was held, so Ctrl+T replays as Ctrl
  held across T. Blocks inside a held key are indented and show the hold time.
- **Open window.** A new Window block that starts a program, or brings it forward if it's already running,
  and waits for its window.
- **Pick programs with File Explorer.** Window blocks and program conditions use File Explorer or the list
  of running programs instead of a typed name.
- **Picture preview.** Picture blocks show the image they look for, and Test on screen checks it right away.
- **Clearer Logic and Detect blocks.** Label pickers for Go to, Wait for window can wait until a window is
  open, and conditions explain themselves.
- **Always on top.** Settings › Appearance keeps Night-loop above other windows.
- **Two-factor made simpler.** New accounts ask for a code on new PCs only. Accounts that never changed this
  setting move to New devices only too. Switching to Every sign-in no longer needs your password, and it now
  asks for a code each time Night-loop opens.
- **Steadier recordings.** Short pauses add up instead of disappearing, and very long recordings are trimmed
  to fit instead of failing to save.

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
