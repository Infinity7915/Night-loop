> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## Fixed

- **Turn with: Arrow keys did nothing.** Scan & turn, Turn camera and Center on target now send the arrow keys the
  way a real keyboard does. Before, games could read them as number pad keys (Num 4 instead of Left), so the camera
  never moved and Scan & turn kept looking at the same view. The same fix covers Home, End, Page Up, Page Down,
  Insert, Delete, right Ctrl/Alt and the Windows keys in every key block.
- Short arrow turns hold the key for at least 50 ms, so a small turn is never too quick for the game to notice.
- With arrow keys, centering on a target only turns sideways. In most games (Roblox too) Up and Down walk instead of
  looking up or down.
- **The right mouse button stayed held after a find**, so just moving the mouse turned the camera. Right-drag turns
  now give the game more time around the press and release, and let go a second time a moment later. An extra
  release changes nothing when the button is already up, but it unsticks a game that missed the first one.
- If Windows refuses to let go of a key or button once, Night-loop tries again when the macro stops, instead of
  forgetting it was held.

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
