> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## New

- **Size tolerance % on picture blocks** (Wait for image, Image gone, Find & click and Scan & turn looking for an
  image, and If / Repeat until with "Image visible"). In a game, a thing farther away looks smaller than when you
  captured it, so it used to be found only from the exact same spot. With a size tolerance of 25, Night-loop also
  looks for the picture from 75% to 125% of its size. New picture blocks start at 25. Blocks you already have
  start at 0, so set it on the ones that miss.
- **Confidence %** and **Color tolerance** on Find & click and Scan & turn. They were fixed at 90% and 10 before.
- **Test on screen now** says how close the best spot came and at what size, so you can see what to change.
- **Editor shortcuts**: Ctrl+Z undoes the last change to the blocks (deleted blocks come back), again and again up
  to 200 steps back, and Ctrl+Y redoes it. Ctrl+C copies the ticked blocks (or the highlighted one), Ctrl+X cuts
  them, and Ctrl+V pastes them under the highlighted block. Delete removes the ticked blocks. Copied blocks stay
  inside Night-loop.
- **Settings › Macros › Editor shortcuts**: change the key for each of these. A shortcut can't be the record key,
  Play (F6), stop-everything, Ctrl+A or Esc, or another shortcut. A macro start key can't be set to a shortcut,
  and a macro that already uses one won't start with it until you change the macro's key or the shortcut.

## Fixed

- **"Delete?" stayed armed.** After pressing a macro's or group's delete button once, it kept asking until the macro
  was closed and opened again. Now it goes back to the plain delete button as soon as you click anything else, press
  a key, switch tabs or switch to another window.
- **Delete and Ctrl+A sometimes did nothing** after clicking a block, because the keyboard was still in a field
  of the block editor. Clicking a block now takes the keyboard off the field.
- **Center on target** (and Scan & turn's centering) looked for the picture at 90% confidence whatever the block
  said, so it could lose a target the block had just found.

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
