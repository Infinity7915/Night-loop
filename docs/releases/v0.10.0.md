If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## Changed

- **Recording is removed. Macros are built from blocks only.** The Record button, the start / stop recording
  key (F9) and the "Record mouse movement" switch are gone from the editor and its options. Night-loop no longer
  installs keyboard or mouse hooks and never watches what you type or click. Build macros with **Add block**
  (keys, clicks, mouse moves, drags, waits, loops, screen reading and more) and set each block up in the side
  panel.
- **Your recorded macros keep working.** Blocks recorded with earlier versions, including mouse moves and
  drags that follow a recorded path, stay in your macros and play exactly as before. You can still edit,
  move, copy and delete them.
- **F9 is free.** It was reserved for recording; now it can be a macro's start key or an editor shortcut.
- The Privacy Policy and Terms of Service now say the App doesn't record keyboard or mouse input.

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
