> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## What's new

- **Public server.** The app now signs in to `https://api.night-loop.win`, so you can create an account
  straight from the app. If that server isn't live yet when you open the app, you'll see "can't reach the
  server" with a Retry button.
- **Themes.** Dark, light or match Windows, with 4 accent colors.
- **Settings.** Pick target games, change your username, email or password, turn on two-factor sign-in,
  download your data or delete your account.
- **Macro editor.** Add blocks from a 7-category palette, edit them in a side panel, add notes, set
  breakpoints, Step through or Run from any block.
- **Saved macros.** Colored groups, search, Save all, and start/stop keys and an on/off switch for each macro.

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
