> **Still an early test build.** Please report anything odd in [Issues](https://github.com/Infinity7915/Night-loop/issues).

If you already have Night-loop, you don't need to download anything: open it and it updates itself.

## What's new

- **Macros tab, rebuilt.** It now matches the design: the loaded macro card with Record, Step, Run from and
  Play, block categories as chips, a timeline with nesting lines, the block editor beside it, and saved macros
  in colored groups with search.
- **38 blocks.** Key combos, hold key, drag, camera zoom and center, wait for key, pause and resume other
  macros, wait for text, image or pixel color, find and click, scan and turn, window focus, resize and
  position, screenshot, notify and more.
- **Pick from the screen.** Block settings can be picked with the mouse: a point, a color, a region, or a
  picture to look for. Window blocks can copy the game window's current size and position.
- **Starter sequence.** New macros begin with blocks that line the game window up, a loop to fill in and a
  notification at the end. Turn it off in Settings › Macros.
- **Smoother playback.** The mouse glides between points instead of jumping, and drags replay as drags.
- **Settings.** Matches the design: Roblox, Fortnite and Minecraft (Java or Bedrock) as target games, account
  changes right in the card, and a simpler Updates card.
- **Resizing fixed.** Rows stack instead of overlapping when the window is narrow.
- **No import or export.** Macros live only on your account, and older app versions can no longer sign in.

## Download

- **NightLoop-win-Setup.exe**: installs Night-loop for your Windows user and keeps it up to date.
- **NightLoop-win-Portable.zip**: unzip anywhere and run `NightLoop.exe`.

Windows may show **"Windows protected your PC"** because the app isn't code-signed yet. Click **More info →
Run anyway**.
